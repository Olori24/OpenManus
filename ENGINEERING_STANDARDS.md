# OAE™ Engineering Standards

This repository is classified as **archived / migrated** under the Open Autonomous Engineer (OAE™) standard.

## Lifecycle rules

- Do not represent this repository as actively maintained when the source has moved.
- Keep the successor location clear and accurate.
- Do not introduce new application functionality solely for repository appearance.
- Preserve historical context where useful.
- Never commit secrets, credentials, or private configuration.
- Changes to archived repositories should be minimal, auditable, and lifecycle-related.

## OAE™ improvement loop

```text
Observe → Understand → Classify → Preserve → Verify
```
